# WCX · 微信增强模块 💠

## 声明一下，本项目属于 wekit 二改，上游: [WeKit](https://github.com/Ujhhgtg/WeKit)

一款基于 Xposed 框架的开源微信增强模块。当前代码里共有 **200+ 个功能开关，分为 20 余个分类**，覆盖聊天增强、界面美化、隐私防护、红包助手、朋友圈、批量操作、系统工具、脚本插件等。

> 🚀 **项目定位**：不仅仅是一个微信模块，更是一个集成了**去混淆分析工具 (deobf)** 的综合项目 —— 从逆向分析到功能实现，一站式搞定。

### 💬 聊天增强

- **防撤回**：两种展示样式二选一 —— 新版「原消息半透明 + 文本 / 图标徽标」，或旧版「插入一条系统提示」（提示内容与时间格式可自定义）；支持把历史遗留的旧版系统提示一键迁移为新样式
- **AI 自动回复 / 关键词自动回复 / 长按智能回复**：可指定触发条件与生效群聊
- **对话分组 / 对话归拢**：主页顶部 Tab 分类筛选；多个对话收进一个文件夹（支持手动添加对话）
- **定时发送 / 群发消息 / 转发消息 / 批量撤回 / 消息复读**
- **消息过滤屏蔽**：按消息类型过滤（私聊 / 群聊 / 公众号独立规则、黑白名单、拦截日志）
- **群内屏蔽指定成员**：只在本机屏蔽指定群成员，支持完全隐藏或静默保留（可在日志回看）
- **消息外观**：合并消息显示、消息进入动画、悬浮标题栏、悬浮输入框、沉浸式状态栏、Markdown 渲染、消息时间增强、消息详情

- **表情**：解除单个表情数量上限、表情面板、表情游戏控制、表情消息以图片打开
- **输入栏**：聊天工具栏、聊天输入栏增强（长按发送 / 加号菜单发送语音文件、卡片消息、@所有人）
- **其他**：禁用拍一拍、禁用消息折叠、解除消息多选限制、解除风险文件拦截、移除媒体发送数量限制、禁止上传正在输入状态、伪造聊天记录消息、伪装语音时长、反安全消息 / 安全消息发送

- **公众号**：公众号去广告、网页多开、恢复旧版列表
- **视频号**：下载媒体、移除评论区广告、解除评论长度限制、崩溃防御

### 🧩 自动化与脚本

- **独立的「脚本」Tab**：插件总开关一键启停；本地插件启用 / 停用 / 排序 / 导入 / 删除 / 查看说明
- **在线插件市场**：浏览插件列表与详情、历史版本；服务器地址支持官方 / 备用 / 自定义切换
- **插件 Agent 工作区**：在手机上直接编写与调试脚本插件
- **实时加载**：修改插件文件后约 0.5 秒自动重载，插件新增 / 删除自动刷新
- **双引擎**：JavaScript（Rhino）与 Java（BeanShell）脚本
- **API 服务器**：启动 MCP 与 REST API 服务器，可让外部程序与 AI 访问微信能力
- **功能诊断**：脚本功能诊断页 + 常见问题页，支持一键自检与一键修复

### 🧪 稳定性与诊断

- **模块自检**：汇总功能总数、各分类启用情况、微信 API 层状态、DexKit 安装任务逐项、关键类锚点探测
- **「上次退出原因」**：读取系统退出原因，区分崩溃 / ANR / 被系统回收 / 用户停止，并统计当日启动次数
- **日志 Tab**：分级日志、按天落盘、一键保存与分享
- **在线特征包**：Hook 点特征支持在线更新，微信更新后无需重发 APK

## 📦 核心模块详解

### 📱 app — Xposed 模块主程序

基于 Kotlin 开发的微信 Xposed 模块，通过 LSPosed 框架注入微信进程，实现各项增强功能。

**核心能力：**
- **Hook 框架**：基于 LSPosed / Xposed API 的方法 Hook，按 Feature 粒度独立开关
- **能力层（features/api）**：把微信内部能力（发消息、数据库、消息视图、XML 解析等）收敛成 API，供各功能复用
- **UI 注入**：向微信界面注入自定义控件和布局
- **脚本引擎**：嵌入式 JavaScript（Rhino）与 Java（BeanShell）运行环境 + 插件市场
- **主题系统**：动态资源替换与主题引擎

### 🔬 deobf — 去混淆分析工具

基于 unidbg ARM64 模拟器的动态解密与去混淆框架，用于分析微信模块的加密载荷。

**功能亮点：**
- **动态脱壳**：在模拟器中运行原生加载器，捕获解密后的 DEX
- **自动化管线**：一键运行，从加密文件到可分析代码
- **Python 工具集**：格式清理、字符串提取、翻译提取等后处理
- **分析报告**：生成详细的分析报告文档

> 详细说明见 [deobf/README.md](deobf/README.md)

### 🦀 xtask — Rust 构建任务

用 Rust 编写的构建辅助工具，提供高效的编译和打包流水线。

### 📖 docs — 完整文档

包含功能说明、安装指南、配置教程、开发文档等完整文档体系：
- 快速开始 / 安装指南
- 模块设置说明 / 配置指南
- 各分类功能说明（聊天 / 美化 / 联系人 / 朋友圈 / 支付 / 系统…）
- 开发指南 / 脚本 API 参考
- 常见问题 FAQ
- 问题反馈指南 / 建议反馈指南
- 免责声明

## 📋 适配版本

> 💡 **推荐使用微信 8.0.77 ~ 8.0.79**，功能完整且经过测试。

| 状态 | 版本范围 | 说明 |
|------|----------|------|
| ✅ 推荐使用 | 8.0.77 ~ 8.0.79 | 功能完整适配，推荐使用 |
| 🔧 维护中 | 8.0.69 ~ 8.0.76 | 基本可用，如有问题欢迎反馈 |
| ⚠️ 低版本 | < 8.0.69 | 部分功能可能无法使用，不推荐 |

- **框架支持**：LSPosed（推荐）、EdXposed、Xposed
- **系统要求**：Android 8.0+（推荐 Android 10+）
- **架构支持**：arm64-v8a、armeabi-v7a
- **构建变体**：`standard`（libxposed 入口，推荐）与 `legacy`（传统 Xposed 入口）

## 🔧 构建

```bash
# 克隆项目（含子模块）
git clone --recursive https://github.com/Johnny520/wcx.git
cd wcx

# 构建 Release 版本
./gradlew assembleRelease

# 构建 Debug 版本
./gradlew assembleDebug

# 运行去混淆分析（需要 Java 环境）
```
