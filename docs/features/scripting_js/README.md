# 脚本引擎

使用 JavaScript 编写脚本扩展微信功能, 支持消息处理、HTTP 请求、Xposed Hook 等。

## 功能列表

- [脚本引擎 (JS)](js-scripting-hook.md) — 执行 JavaScript 脚本
- [触发器：发起请求 (JS)](on-request.md) — 发起请求时是否执行 onRequest()
- [触发器：收到响应 (JS)](on-response.md) — 收到响应时是否执行 onResponse()
- [触发器：收到消息 (JS)](on-message.md) — 收到消息时是否执行 onMessage()
