# 首页右上角菜单

加到微信主界面右上角「+」菜单里的模块入口与快捷操作。

## 功能列表

- 一键隐藏对话 — 在首页右上角菜单添加一键隐藏对话入口, 可全选/单选对话进行隐藏 (仅从列表移除, 保留聊天记录), 支持定时执行
- 强行停止 — 在首页右上角菜单添加「强行停止」选项
- 显隐全部对话 — 在首页右上角菜单添加菜单项, 可显示或隐藏全部对话
- 朋友圈消息入口 — 在首页右上角菜单加一项，直接进入朋友圈消息列表（打开即清红点）
- 模块设置 — 在首页右上角菜单添加「WCX」选项
- 清空未读 — 在首页右上角菜单添加「清空未读」选项
- 禁止主页下滑进入最近页面 — 禁止主页下滑进入最近页面，支持通过加号菜单和标题栏图标唤起小程序面板
- 跳转对话菜单 — 在首页右上角菜单添加「跳转对话」选项
