# 小程序

小程序功能提供广告移除、限制解除等增强体验。

## 功能列表

- Eruda 调试面板 — 小程序页面注入 Eruda 调试控制台
- [伪装宿主版本](spoof-host-version.md) — 解决提示版本较低无法使用部分小程序
- [去除菜单限制](remove-menu-limits.md) — 移除小程序右上角菜单的限制
- [移除嵌入广告](remove-embedded-ads.md) — 移除小程序嵌入广告
- [移除开屏广告](remove-splash-ads.md) — 跳过小程序开屏广告
- [移除视频广告](remove-video-ads.md) — 跳过小程序视频广告
- 绕过防沉迷 — 绕过微信游戏小程序的未成年防沉迷 绕过后可能没有声音, 看广告能恢复
- [跳过启动页面](skip-splash.md) — 跳过小程序启动页面, 变相去广告 (实验性)
- 跳过激励广告 — 跳过小程序激励广告: 广告展示后立即视为看完并发放奖励
