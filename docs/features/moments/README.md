# 朋友圈

朋友圈功能提供广告拦截、内容增强和更多自定义能力。

## 功能列表

- 上传原图 — 上传时不压缩图片, 过大可能上传失败
- 伪集赞 — 自定义朋友圈点赞用户列表
- [单击不关闭视频播放器](no-close-video-player-on-click.md) — 朋友圈视频播放器内单击视频将展开/折叠控制栏而非关闭视频 (遇到长视频下意识点一下就给我视频关了, 有点反人类了)
- 发现页朋友圈入口隐藏 — 「发现」页里的「朋友圈」一行不再显示（不影响朋友圈本身的数据与其它入口）
- 常驻互动消息入口 — 没有未读互动消息时也在朋友圈顶部显示互动消息入口
- [底部详细信息](display-details.md) — 在朋友圈列表项底部显示详情信息
- [拦截朋友圈广告](remove-moments-ads.md) — 拦截朋友圈广告
- 朋友圈关键词屏蔽 — 按关键词屏蔽朋友圈动态，支持好友范围、白名单、关键词分组、匹配模式
- [朋友圈查询增强](enhance-query.md) — 显示历史撤回以及缓存过的朋友圈内容
- 朋友圈编辑界面返回逻辑优化 — 编辑朋友圈返回弹出「保留当前内容?」对话框后, 触发系统返回手势可直接关闭对话框并留在编辑页
- 朋友圈评论防撤回 — 拦截朋友圈评论删除并添加标记
- 朋友圈防撤回 — 拦截他人朋友圈删除并添加标记
- [消息转圈](forward-messages-to-moments.md) — 将一些简单的消息转发到朋友圈
- 点击空白处查看详情 — 点击一条朋友圈的空白区域直接进入该条朋友圈的详情页面
- 禁止自动播放视频 — 禁止朋友圈中的视频自动播放
- 自动刷新 — 定时自动刷新朋友圈列表
- 自动点赞 — 浏览朋友圈时自动点赞
- 自动转发 — 浏览或同步朋友圈时, 自动转发指定目标的朋友圈到自己的朋友圈
- 自定义尾巴 — 自定义发表朋友圈显示的应用来源
- 自定义底部详细信息 — 长按朋友圈自定义该条底部详细信息 需同时打开「朋友圈/底部详细信息」
- 转发 & 一键转发 — 转发他人的朋友圈, 支持实况图片 图片/视频会在转发前自动缓存, 无需先点开; 实况视频如转发后空白请先播放一次
