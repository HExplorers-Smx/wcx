# 红包与支付

红包与支付功能提供微信支付和红包的增强体验。

## 功能列表

- [修改显示余额](modify-wallet-balance-display.md) — 伪装钱包余额文字 零钱与零钱通分开设置：各自支持固定文本或实时增减（发红包后自动变化）
- [修改转账显示余额](modify-transfer-wallet-balance-display.md) — 伪装转账时显示的余额文字
- [允许领取私聊红包](allow-private-chat-receive-outgoing-red-packets.md) — 允许打开私聊中自己发出的红包 可能导致发送红包提示「请求不成功」
- 抢红包金额统计 — 本地统计抢到的红包金额与数量，数据仅保存在本机
- [指纹支付](fingerprint-pay.md) — 使用指纹快捷确认支付
- 捡漏历史红包 — 在联系人与群组详情页面添加选项, 批量扫描当前对话的所有历史红包消息并尝试领取 点击可查看当前正在进行的任务
- 红包页面详情 — 红包领取页面显示更加详细的领取情况
- [自动抢红包](auto-open-red-packets.md) — 监听消息并自动拆开红包
- [自动接收转账](auto-accept-transfers.md) — 监听消息并自动接收转账
