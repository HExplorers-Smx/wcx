# 联系人与群组

联系人与群组功能提供了联系人管理、群组信息增强等能力。

## 功能列表

- 修改好友数量 — 修改联系人页显示的好友数量，不会改变实际联系人数据
- [分裂群组](split-group-chats.md) — 让群聊一分为二; 在假群聊中发送的红包即为假红包
- [分裂群组通话](split-group-chats.md) — 随机生成假群 ID, 并发起群通话或实时对讲后终止推送到他人手机
- 删除假群组 — 彻底清除假群组 (仅清除本地数据库，不影响原群)。
- 加入群聊自动免打扰 — 加入新的群聊后自动开启消息免打扰
- [圆角头像](round-avatars.md) — 自定义微信全局头像渲染的圆角弧度
- 快捷打开朋友圈 — 在首页对话列表长按菜单添加菜单项, 可点击一键跳转到朋友圈
- [显示微信 ID](show-wx-id-in-contact-details.md) — 在联系人与群组详情页面显示微信 ID
- [显示隐藏朋友设置项](display-hidden-contact-settings.md) — 阻止微信隐藏朋友设置; 部分设置项可能显示异常, 但不影响功能
- 查看群成员消息历史 — 在联系人与群组详情页面添加入口, 可查看任意群成员的全部历史消息
- [检测单向删除好友](detect-deleted-friends.md) — 批量扫描全部好友, 检测是否被对方单向删除
- 添加自动备注 — 添加好友时自动备注
- [移除消息批量转发限制](remove-message-batch-forward-limit.md) — 移除消息多选目标的 9 个数量限制
- 移除群成员昵称控制字符 — 自动移除群聊成员昵称中影响显示的 Unicode 控制字符
- 自动同意好友申请 — 自动同意好友申请，支持延迟设置、自动发送欢迎语、黑名单过滤
- 自动添加附近的人 — 在附近的人菜单中添加菜单项, 可全自动向附近的人按模板发送消息
- [自定义好友本地头像](custom-local-friend-avatars.md) — 为指定联系人或群组使用本地图片替换显示的头像
- 解除群成员昵称长度限制 — 移除微信为群成员昵称设置的固定最大宽度, 让昵称尽可能使用消息区域的可用空间
- [跳转对话](open-conversation.md) — 打开指定微信 ID 的对话/好友主页/好友设置界面
- 限制群成员昵称长度 — 限制群聊中成员昵称的最大显示长度（不计模块注入的文本）
- [隐藏联系人](hide-contacts.md) — 隐藏指定的联系人
