# 防撤回

> 阻止撤回消息

## 类别

聊天

## 类型

可开关 & 可点击

## 描述

拦截对方与自己撤回的消息：撤回后原消息依然保留在聊天里，同时按所选样式给出提示。

## 使用方法

在模块设置中启用后, 可点击以进行详细配置。

## 展示样式（二选一）

防撤回提供两种展示方式, 二者只能启用其中一种：

1. **徽标样式（默认）**
   原消息保持可见但整体半透明, 并在气泡旁显示一枚徽标。徽标可选择「文本」或「图标」。
2. **旧版样式**
   在原位置插入一条系统提示消息, 提示内容与时间格式都可以自定义。
   打开「旧版样式」后, 徽标样式自动停用。

## 设置项

| 设置项 | 说明 |
| --- | --- |
| 防撤回自己 | 自己撤回的消息同样保留 |
| 徽标类型 | 选择用文本还是图标作为徽标 |
| 迁移旧版提示 | 把历史上由旧版样式插入的系统提示, 批量迁移为当前样式的展示 |
| 旧版样式 | 切换到「插入系统提示」的旧版展示方式 |
| 旧版提示内容 | 自定义旧版系统提示的文案 |
| 时间格式 | 自定义旧版系统提示中时间的显示格式 |

> 迁移旧版提示只处理最近的系统提示记录, 迁移过程中会显示进度, 可随时退出。迁移后这些历史记录会按当前样式重新显示。

## 说明

- 撤回的消息只在本地保留, 不会重新发送给任何人
- 迁移只是改变本地的展示方式, 不会修改微信服务器上的任何数据
- 与「朋友圈防撤回」「朋友圈评论防撤回」是相互独立的功能
