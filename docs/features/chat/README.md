# 聊天功能

聊天功能提供了消息增强、输入栏优化、群管理等一系列聊天体验提升。

## 功能列表

- AI 自动回复 — 接入 AI 大模型自动回复消息，支持 OpenAI 兼容接口，可选择触发条件和指定群聊
- [Markdown 渲染](markdown-rendering.md) — 渲染 Markdown 消息
- 「添加的单个表情」管理器增强 — 在「整理」界面底栏的添加更多功能
- 一键撤回并重新编辑 — 向消息长按菜单添加菜单项, 可快捷撤回消息并将文本内容加入输入框
- [伪装语音时长](fake-voice-duration.md) — 预设定伪装发送语音显示的时长
- [伪造聊天记录消息](fabricate-chat-history-message.md) — 创建伪造的聊天记录并生成卡片消息 XML
- 保存到面板 — 在表情或语音消息菜单添加保存按钮, 可选择对应面板中的目标包
- [修改文本消息显示](modify-text-message-display.md) — 向消息长按菜单添加菜单项, 可修改本地消息显示内容
- 关键词自动回复 — 独立关键词匹配自动回复，私聊和群聊规则独立，支持批量关键词配置与自定义回复文本
- 分享进化 — 让微信的系统分享菜单更易用
- 半屏相册选择器 — 将聊天「+」面板的相册选择器、图片预览和搜索页显示为半屏卡片, 上方可看到聊天内容 (图片编辑器保持全屏)
- 反安全消息 — 无视自己或别人发送的消息中的安全属性，长按消息始终显示正常、完整菜单
- [合并消息显示](merge-messages-into-groups.md) — 将同一发送者的连续多条消息合并为一组消息显示 (Telegram 风格)
- 图片保存到本地 — 在图片消息菜单添加保存按钮, 允许将图片文件缓存并保存到本地
- 安全消息发送 — 在自己发出的文本消息 msgsource 中注入 sec_msg_node 标记，双方长按该消息只剩「删除」选项。被动模式：对所有发出的文本消息生效；主动模式：长按发送按钮或使用触发前缀，仅对特定消息生效
- 定时发送消息 — 在指定时间发送消息到群聊或私聊，支持每天重复或单次发送，支持多种消息类型
- [对话分组](conversation-grouping.md) — 向主页顶部添加 Tab 栏, 将对话分组 建议同时启用「界面美化/隐藏主页下滑「最近」页」
- 对话归拢 — 将多个对话归拢在一个文件夹内 设置对话头像需同时启用「自定义好友本地头像」
- 左划对话菜单 — 在主页对话列表向左滑动展开菜单, 可对对话执行隐藏或删除等操作 点击配置可选择启用「置顶」和「免打扰」快捷按钮
- 已读追踪(废弃) — 旧版服务端模式仅抓取消息送达记录，极易造成认知误解；当前本地模式更加无法查看他人消息已读状态。功能停止维护，不修复BUG、不新增功能，长期保留入口。
- [引用消息直达](quoted-message-direct-jump.md) — 点击被引用消息时直接跳转至对应消息
- 强制启用所有功能 — 在聊天工具面板中强制启用所有功能
- 快捷回底 — 聊天界面离最新消息超过一定距离时, 复用右下角「x条新消息」气泡显示「回到最新」, 点击一键回到最新消息
- [快捷清除引用](quick-remove-quote.md) — 在输入退格时若输入框无文字自动清除引用
- 悬浮标题栏 — 将聊天界面顶部标题栏及标题下方挂件改为悬浮卡片形式, 带有圆角、阴影和侧边距
- 悬浮输入框 — 将聊天输入框改为悬浮卡片形式, 带有圆角、阴影和侧边距
- 批量撤回 — 向消息长按菜单添加菜单项, 可批量撤回消息
- [拦截异常大小贴纸表情](block-abnormal-size-stickers.md) — 拦截某些异常大小表情导致的闪退现象
- 文件下载到本地 — 在文件消息菜单添加下载按钮, 允许将文件缓存并保存到本地
- [显示消息详情](display-message-details.md) — 向消息长按菜单添加菜单项, 可查看消息详情
- 显示群成员实名全字 — 整合「爆破群成员实名首字」与「显示群成员实名尾字」的结果, 在昵称旁同时显示首字与尾字
- [显示群成员实名尾字](display-group-member-real-names-last-char.md) — 通过转账接口获取并显示群成员的实名尾字
- [显示群成员身份](display-group-member-roles.md) — 在群聊中显示群成员的身份: 群主, 管理员, 成员
- 查看群成员邀请者 — 在群成员详情页面添加入口, 可查看该成员的进群邀请者
- [消息复读](repeat-messages.md) — 向消息长按菜单添加菜单项, 可复读一些常见消息
- 消息时间增强 — 显示精确消息发送时间并允许显示更多详情
- 消息类型过滤屏蔽 — 按消息类型过滤屏蔽，支持私聊/群聊/公众号独立规则，生效范围控制，模板管理，黑/白名单，拦截日志
- 消息进入动画 — 聊天界面中单条消息进入屏幕时播放入场动画, 支持弹跳/平移滑入/重力掉落, 可让历史消息全跳动
- 消息长按菜单项合并展示 — 开启后, 消息长按菜单只显示一个 WCX 项, 点击后在对话框中集中展示所有模块菜单项
- 添加对话至归拢文件夹 — 在首页对话列表长按菜单添加菜单项, 可将该对话加入「对话归拢」的手动文件夹 需启用「对话归拢」
- 滑动消息快捷操作 — 在消息上滑动以引用, 并可选复读或编辑为次要操作
- [爆破群成员实名首字](exploit-group-member-real-names-first-char.md) — 通过大额转账的姓名校验接口, 逐一尝试并还原群成员实名的首字 (与显示实名尾字功能配合可拼出完整姓名). 会向服务器发起多次转账下单 (不会真正扣款), 有触发风控的风险, 请自行承担
- [禁止上传正在输入状态](disable-typing-status-uploading.md) — 禁止微信上传「对方正在输入」状态
- 禁用拍一拍 — 双击他人头像时不发送拍一拍
- [禁用消息折叠](disable-message-collapsing.md) — 阻止聊天消息被折叠
- [禁用置顶聊天折叠](disable-pinned-chats-collapsing.md) — 隐藏「折叠置顶聊天」选项 启用本功能后, 需重启微信 2 次以使更改完全生效
- 禁用输入框快捷语音转文字 — 隐藏输入框右侧的语音转文字按钮
- [移除媒体发送数量限制](remove-send-media-count-limit.md) — 移除发送媒体的数量限制
- [移除消息菜单项](remove-chat-message-context-menu-items.md) — 从消息的长按菜单中移除指定名称的菜单项
- 群内屏蔽指定成员 — 只屏蔽指定群里某些成员的消息，本机生效、对方无感；支持完全隐藏与静默（可在日志里回看）两种模式
- 群成员行为监控 — 监控群成员的退群与修改群昵称行为
- [聊天工具栏](chat-toolbar.md) — 在输入框上方添加工具栏
- [聊天输入栏增强](chat-input-bar-enhancements.md) — 为聊天输入栏添加更多功能 在聊天界面长按「发送」或「加号菜单」按钮打开菜单 菜单功能: 「发送语音文件」「发送卡片消息」「@所有人」
- 聊天输入栏钩子 — 集中提供聊天输入栏相关钩子
- 聊天页沉浸式透明状态栏 — 聊天界面状态栏全透明，聊天背景向上延伸填充状态栏区域
- [自动启用发送原图](auto-enable-no-compress-on-send-media.md) — 发送媒体时自动勾选发送原图选项
- 自动启用合并发送媒体 — 发送媒体时自动勾选「发送后合并展示」选项
- [自动查看原图](auto-view-original-media.md) — 在打开图片和视频时自动点击查看原图
- 自动缓存图片 — 监听接收到的图片消息, 自动触发微信从 CDN 下载, 将原图缓存到本地
- 自动缓存文件 — 监听接收到的文件消息, 在对方上传完成后自动触发微信内部下载将其缓存到本地
- [自动语音转文字](auto-speech-to-text.md) — 自动将语音消息转为文字
- 自定义输入框占位符文本 — 自定义聊天输入框中显示的占位符文本 统计信息每天自动清除
- 表情消息以图片打开 — 点击聊天中的贴纸时使用微信原生图片查看器打开
- [表情游戏控制](emoji-game-control.md) — 自定义猜拳和骰子的结果
- 表情面板 — 长按表情按钮打开表情面板
- 解除单个表情数量上限 — 解除表情面板「添加的单个表情」分类的 999 个数量上限, 允许无限添加图片表情
- 解除消息多选数量限制 — 解除聊天界面消息多选至多只能选择 100 条的限制
- 解除风险文件拦截 — 绕过“此文件已被用户投诉并核实存在安全风险，无法接收/无法打开”的提示，允许正常接收和打开被标记的文件
- [语音保存到本地](save-voices-to-local-storage.md) — 在语音消息菜单添加保存按钮, 允许将语音文件保存到本地
- 语音消息播放逻辑优化 — 优化语音消息听筒/扬声器自动切换: 完全禁用自动切换, 或切换后继承播放进度不再从头重播
- 语音面板 — 长按语音按钮打开语音面板
- [贴纸保存到本地](save-stickers-to-local-storage.md) — 在贴纸消息菜单添加保存按钮, 允许将图片保存到本地
- [贴纸包同步（已移除）](stickers-sync.md) — 此功能已移除，贴纸本地导入功能不受影响
- 超级对话置顶 — 在首页对话列表长按菜单设置优先级, 置顶和非置顶对话分别按优先级排序
- [转发收藏语音](forward-favorite-voices.md) — 在聊天菜单的「收藏」中允许转发语音
- 转发消息 — 在消息长按菜单添加转发按钮, 可向好友或群聊批量转发
- [重定向文件下载路径](redirect-download-path.md) — 将微信接收的聊天文件保存到自定义文件夹
- 长按智能回复 — 消息长按菜单添加「智能回复」: AI 生成多条备选回复, 点击直接发送 (需在设置中配置 OpenAI 兼容接口与 API Key)
- [防撤回](anti-message-recall.md) — 阻止撤回消息
- 隐藏消息头像 — 隐藏消息的用户头像 (Telegram 风格)
