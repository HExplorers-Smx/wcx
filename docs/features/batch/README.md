# 批量操作

批量处理好友、对话与消息；所有会触发服务器请求的操作都会自动间隔，尽量避免风控。

## 功能列表

- 导出聊天记录 — 导出选中对话的聊天记录为 TXT / CSV / JSON 格式，保存到 Download/WCX 目录
- 批量免打扰 — 选择多个好友或群聊后, 批量开启或关闭消息免打扰
- 批量删除好友 — 选择多个好友后一次性删除, 请求会自动间隔以规避服务器风控
- 批量删除聊天记录 — 彻底清除选中对话的聊天记录 (删除 rconversation 与 message 记录), 此操作不可逆!
- 批量打标签 — 为选中的多个好友追加同一个标签, 可选择已有标签或新建, 请求会自动间隔以规避服务器风控
- 批量标为已读 — 选择多个好友或群聊后, 将它们的对话一次性标记为已读
- 批量隐藏对话 — 从对话列表移除选中的对话 (仅删除 rconversation 记录, 保留聊天记录), 重新收到消息时对话会再次出现
- 群发消息 — 编写一条文本或卡片消息, 选择多个好友或群聊后批量发送, 请求会自动间隔以规避服务器风控
